# Beat The Mess Rush 🍽️

**Know the crowd. Find your calm. Make mealtime easier.**

## About the Project

Beat The Mess Rush is a first-year Design Thinking project focused on a familiar campus challenge: students may reach the mess without knowing how crowded it is or whether seats are available.

Our prototype presents meal-wise crowd information and provides separate areas for student updates and manager seat updates. It is designed around three meal periods: breakfast, lunch and dinner.

## Prototype Features

### 1. Dashboard
- Select breakfast, lunch or dinner.
- View occupied seats, empty seats and total capacity.
- See the displayed occupancy percentage and crowd level.
- Review recent student-submitted crowd reports.

### 2. Student Update
- Enter a student name.
- Select a meal.
- Submit a Low, Moderate or High crowd estimate.
- Optionally enter an estimated crowd number.

### 3. Manager Panel
- Select a meal.
- Set total seating capacity.
- Update the occupied-seat count.
- View the resulting empty-seat count and occupancy percentage.

## Technology

- HTML
- CSS
- JavaScript
- Browser local storage for the current demonstration prototype

## How to Run

1. Download or clone this repository.
2. Open `indexmain.html` in a modern web browser.
3. Use the Dashboard, Student Update and Manager Panel sections to explore the prototype.

## How the Prototype Handles Updates

The current version saves its demonstration data in the browser's local storage. Student reports and manager seat updates are reflected in the interface in that browser. This version does not use a cloud database and does not synchronize data between different devices.
